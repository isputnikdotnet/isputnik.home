Device Sync

Members' phones back up photos and videos to their personal libraries. Check here that it's working.

Set up phone backup

Three things, once. Then each member adds their own phone.

  1. Allow personal librariesEvery member · 50 GB each · Family media › Personal
  2. 2
    Choose where phones may back up fromYour home network, plus a VPN range for backing up away from home.
  3. 3
    Set the address phones useThis server on your home network, with its port, such as http://192.168.2.10:4000.
  4. Then, each memberProfile › My library › Add a phone, and follow the card.
Until it's set up, the page is just this checklist; the phone list appears once the first phone has been added. Each step opens the same editor the running page uses.
