# Library control panel — interactive mockup

Open `dist/index.html` directly in a browser. No server or dependencies are needed.
All five navigation tabs work; Libraries supports search, type filtering and sample
management dialogs. Organization opens example editors. Device Sync opens setup,
status and settings dialogs. Storage has expandable folder details and links to the
app storage inventory.

This is a standalone design artifact with fictional data, not application code.
It has no API connections, credentials or access to the household's files. Changes
are illustrative and reset on reload. Existing application UI components and
English/Russian translations should be used when implementing the approved design.

Source: `dist/index.html`, `dist/style.css`, `dist/app.js`.
Design rationale: [Improving control panel libraries](../../library-control-panel-review.md).
